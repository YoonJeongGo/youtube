로컬에는 코드·규칙·기획·상태와 `보관기록/2026-11-24/`의 작업 재개 안내, 원문 텍스트 보존 ZIP, 검증·정리 영수증을 유지했다. 개인 PC 경로를 포함한 원문 텍스트 ZIP은 로컬 보존용이며 공개 사본의 경로 정제와 구분한다. GitHub의 미디어 바이트는 원본 그대로다. 공개 텍스트 사본의 원본/공개 SHA-256은 각 archive_manifest.json에 있다.

현재 `episodes/`와 전달 폴더의 미디어 및 프로젝트 전용 Python 가상환경·모델 캐시는 비워졌다. 과거 상태·승인 이력은 보존된 기록이고 즉시 렌더할 수 있다는 뜻은 아니다. 기존 편을 이어가려면 필요한 ZIP을 빈 복원 폴더에 내려받고, 해시를 대조하고, 원문 상태·승인과 실제 입력 파일을 연결한 뒤 의존성을 준비한다. 공유 시스템 Python·FFmpeg·Codex 채팅·다른 프로젝트와 C 경로의 호환 junction은 유지했다.

이번 삭제는 명시적인 일회성 요청이다. 새 결과물을 자동 삭제하지 않는다. 보관 성공과 영상 품질 검수, 사용자 음성 청취 승인을 혼동하지 않는다.

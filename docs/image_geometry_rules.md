# 손·팔·무기 연결과 동작 우선 카메라: 공통 이미지 기준

2026-11-19 사용자 영구 지시. 정책 ID: action_anatomy_continuity_v1.
쇼츠·롱폼의 신규 생성, 현재 사용 예정인 기존 이미지, 수정·재검수 모두에 적용한다. 이번 홍길동 VS 로빈 후드 롱폼도 대상이며 특정 대진·구도를 공통 기본값으로 만들지 않는다.

## 행동과 카메라

- 어디를 보고 어느 방향으로 이동하며 무엇을 하는지 먼저 정하고, 몸의 지지·무게중심·손과 도구의 위치를 설계한 뒤 카메라를 선택한다.
- 정면·측면·뒷모습·사선·어깨너머·위/아래 시점을 자유롭게 쓴다. 정면 컷 비율이나 얼굴 노출량은 맞추지 않는다. 양쪽 얼굴을 동시에 보여줄 필요도 없다.
- 도주는 뒷모습, 궁수는 측면/어깨너머, 담 넘기는 등·다리 동작이 읽히는 시점이어도 된다. 이유 없이 카메라를 보게 하거나 얼굴을 드러내려 목·허리·골반·팔다리를 비틀지 않는다.
- 연결이 불명확하면 인물 간 간격, 팔·무기의 위치, 자세와 카메라를 바꾼다. 특정 컷의 사용자 구도 요청도 자연스러운 인체·공간 관계 안에서 구현한다. 핵심 행동·전제까지 바꾸는 수정은 그 변경 범위를 구분한다.

## 인물별 손과 팔의 소유

- 각 손의 주인을 지정하고 손 → 손목 → 팔꿈치 → 어깨가 같은 몸으로 이어지는지 추적한다. 화면 좌우와 인물의 실제 왼손/오른손을 구분한다.
- 겹친 인물에서는 앞사람의 손이 뒤 사람 팔에 붙거나 서로의 팔이 융합되지 않는지 확인한다. 소유와 연결이 불명확하면 PASS가 아니다.
- 목·어깨·골반·무릎·발목, 지지하는 발과 균형도 행동에 맞아야 한다. 손을 고치면서 팔이나 몸통을 비틀지 않는다.

## 무기 전체와 손 앞뒤의 연속성

- 창·봉·칼 등의 끝에서 끝까지 형태를 추적한다. 손이나 물체에 가려진 양쪽 부분의 중심축·위치·두께가 같은 무기로 자연스럽게 이어져야 한다.
- 곧은 창대가 손에서 갑자기 꺾이거나 단차·굵기 불연속이 생기거나 서로 다른 무기처럼 연결되면 불합격이다. 자연스러운 원근 변화와 실제 구조 오류를 구분한다.
- 휘어짐·파손은 대본에서 의도한 경우에만 원인과 상태를 명확히 표현한다. 생성 오류를 합리화하려 사후 설정을 붙이지 않는다.
- 활은 몸·시선·활·시위·화살과 잡는 손/당기는 손이 같은 발사 동작으로 성립해야 한다.

## 손과 물체의 접점 및 지지

- 손이 자루를 실제로 감싸 쥐는지, 손바닥·손가락·물체가 뒤섞이거나 관통하거나 손잡이에서 분리되지 않는지 확인한다.
- 방패는 드러난 어깨·팔 방향과 방패 위치가 자연스러운 지지 자세로 이어져야 한다. 보이는 손잡이/끈/팔 접점을 확인하되 숨겨진 지지 구조를 전부 노출하지 않는다.
- 자루를 멘 자세에는 어깨·팔·몸통이 무게를 지탱하는 동작이 있어야 한다. 공격/방어 접점과 회피 공간 및 도구 소유도 명확해야 한다.

## 자연스러운 가림과 원근

- 방패·망토·투구·옷·몸·무기 뒤로 손이나 팔이 가려져도 된다. 모든 관절·손가락 다섯 개를 노출하거나 손을 억지로 펼치도록 요구하지 않는다.
- 보이는 부분을 이었을 때 같은 인체가 성립하고 다른 사람 신체와 혼동되지 않아야 한다. 가려진 것과 실제 누락/비정상 연결을 구분한다.
- 후면·측면·얼굴 비노출 자체를 불합격시키지 않는다. 반대로 설명되지 않는 구조를 화풍·역동성·가림으로 정당화하지 않는다.

## 인물과 앞뒤 컷의 일관성

- 복장 색·형태·문양, 머리 모양/색, 체형·비율, 무기/소품 디자인, 칼집·화살통 장착 위치를 기준과 맞춘다.
- 얼굴이 보이면 기준 얼굴을, 보이지 않으면 복장·체형·머리·장비로 동일 인물을 확인한다.
- 이동 방향, 상대와 위치 관계, 겨누는 방향, 잡는 손, 소품 상태가 앞뒤 행동과 이어져야 한다. 단순 좌우 반전으로 사용 손이나 장비 위치를 바꾸지 않는다.
- 맥락이 확립된 손/무기 근접 컷에 두 인물 전신·얼굴을 강제하지 않되 행동 주체와 소유·공간 관계는 식별 가능해야 한다.

## 실제 열람, 수정, 재검수

1. 원본 전체를 열어 행동·구도·인물 간 위치를 본다.
2. 인물별 손과 팔 연결, 무기 전체/손 앞뒤, 그립/방패 접점을 필요한 실제 해상도의 상세 보기로 확인한다.
3. 기준 인물·앞뒤 컷·최종 사용 크롭/프레임을 함께 대조한다.
4. 문제 위치·소유자·결함과 수정 지시를 기록하고 승인 범위에서 수정·재생성한다. 정상 컷은 재사용한다.
5. 수정한 같은 부위를 다시 열고 원본 전체도 본다. 주변의 다른 손·관절·무기·복장에 새 오류가 없는지, 영향받은 인접/재사용 컷도 확인한다.
6. 미해결은 REPAIR, 미열람은 UNREVIEWED와 남은 문제를 기록한다. 파일 존재·프롬프트 문구·자동 형식 검사·해시 일치만으로 시각 PASS를 만들지 않는다.

기존 image_review.json에 현재 이미지/참조/검수 증거 해시, 실제 관찰, 결함·수정 지시와 수정 후 결과를 연결한다. 보이지 않는 관절을 직접 보았다고 쓰지 말고 정상 가림이라고 판단한 근거를 구분한다. 이전 PASS에 새 항목 관찰이 없으면 같은 해시라도 이번 사용 전에 필요한 검수를 보완한다. 기존 이미지·실패/수정 이력·횟수는 보존하며 파일명/컷 ID 변경으로 한도를 초기화하지 않는다.

## 실제 프롬프트와 제작 순서

- 생성 전에 행동/이동·시선 → 지지 자세 → 손/무기 소유와 접점 → 카메라 → 외형/컷 연속성을 구체화한다. asset_tools.py prepare-prompt로 공통 기준을 연결하고 그 완성 프롬프트를 실제 생성/편집에 사용·보존한다.
- asset_tools.py review-template으로 기존/신규 사용 예정 이미지의 현재 계약 재검수 초안을 만들 수 있다. 초안은 전부 UNREVIEWED이며 실제 열람·시각 PASS를 자동 생성하지 않는다. 정확한 호출 문법은 해당 명령 --help를 따른다.
- 승인된 대본의 전체 이미지 초안을 실제 등장 순서로 먼저 전달하는 기존 절차는 유지한다. 초안 전달은 품질 PASS가 아니다.
- 최종 사용할 기존/신규 이미지는 사용자 지적 여부와 무관하게 검수한다. 같은 승인된 행동·전제를 유지하는 수정·재생성·재검수는 컷마다 승인을 반복 요청하지 않는다. 전체 초안 전달을 개별 컷의 무한 수정으로 지연하지 않는다.
- 현재 미승인 대본/전제 재구성의 제작 승인을 규칙 저장이나 기존 이미지 검수로 대신하지 않는다. 그림 수정만으로 새 대본·음성·최종 청취 승인을 얻었다고 쓰지 않는다.
- 그림만 바뀌고 오디오·시간 배치 동일성이 확인되면 기존 유효한 청취 승인을 그 범위에서 유지하고 영향받은 시각 검수를 갱신한다.

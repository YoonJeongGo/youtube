## 보존·복원 시 확인

- 이번 보관을 위해 원본 파일을 삭제하지 않았다. ZIP은 Git 소스가 아니라 GitHub Release 첨부다.
- 파일에 저장된 COMPLETE/NEEDS_REVIEW 등의 상태를 그대로 표시했다. COMPLETE 표기만으로 현재 청취·음향 검수가 통과했다고 다시 판정하지 않으며, 원래 미확인은 그대로 남는다.
- 개인 PC의 홈/프로젝트 경로 접두는 공개 텍스트에서 자리표시자로 치환했다. 인증정보·모델 가중치·가상환경·전체 채팅 기록은 보관 범위가 아니다. 이미지·영상·음원 바이트는 패키징 검증 기록에 따라 보존했다.
- 경로 정제 때문에 공개 메타데이터의 SHA-256은 원래 QA가 참조한 파일 해시와 다를 수 있다. 남아 있는 원본 QA 해시는 당시 검수의 역사적 증거이며 공개 사본에 맞춰 재결합하거나 PASS로 갱신하지 않았다.
- ZIP/서버 해시 일치는 저장·전송 무결성 확인이다. 제작 QA 재실행, 완전한 과거 이력 복원, 유튜브 게시를 뜻하지 않는다. 미디어와 원본/공개 메타데이터의 대응을 ZIP 내부 manifest로 확인한다.
- 별도 복원 폴더에서 먼저 펼쳐 제목·편 번호·버전·작업 ID·누락 범위를 확인한다. 코드/의존성과 필요한 로컬 모델·실행 환경은 별도로 준비한다.
- 링크는 최종 Release 태그 `archive-2026-11-18` 기준이다. 이 생성기는 원격 공개 상태나 다운로드 링크를 직접 확인하지 않으며 검증된 업로드 영수증의 바이트 근거만 연결한다.

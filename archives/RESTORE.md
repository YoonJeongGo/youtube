# 내려받기와 복원

- 영상만 필요하면 편별 `delivery` ZIP을 받고 일반 압축 해제합니다. video.mp4, captions.srt와 저장된 제목·설명·썸네일·검수 자료를 포함합니다.
- 편집 원본이나 전체 수정 이력은 해당 묶음의 모든 `part001`, `part002`… ZIP을 한 폴더에 받습니다. 각 ZIP은 독립된 정상 ZIP이며, 파일 조각을 바이너리로 이어 붙이지 않습니다.
- 중복 원본을 반복 저장하지 않기 위해 `editing`/`history` ZIP은 내용 해시별 객체와 원래 경로 목록을 사용합니다. 아래 도구가 원래 폴더와 파일명을 복원합니다. Python 3.10 이상, 추가 패키지는 필요 없습니다.

```powershell
python archives/restore_archive.py --parts-folder D:/다운로드 --group shorts-001-editing-20261124 --destination D:/복원/숏폼001
```

대상 폴더는 새 폴더 또는 빈 폴더여야 합니다. 기존 제작 폴더 위에 덮어쓰지 않습니다. 공통 자료도 같은 방식이며 group에는 ZIP 이름의 `-part001.zip` 이전 부분을 입력합니다.

각 ZIP의 크기·SHA-256은 catalog.json 및 편별 안내와 대조할 수 있습니다. 복원기는 모든 고유 파일의 SHA-256을 다시 검사합니다. 여러 묶음을 복원할 때는 각각 다른 빈 폴더를 사용하고 필요한 내용을 비교해 합칩니다.

미디어 바이트는 원본 그대로입니다. 공개 사본의 텍스트에는 개인 홈 경로를 `<USER_HOME>`으로 가린 곳이 있습니다. 원본/공개 해시는 archive_manifest.json에 따로 기록했습니다. 과거 검수 파일 내부의 원본 해시를 공개 사본에 맞춰 바꾸거나 PASS 상태를 승격하지 않았습니다. 실행 환경·모델·캐시·인증정보·전체 채팅 기록은 포함하지 않습니다.
